Perguntas Frequentes

De onde vêm os dados salariais?

Os dados são coletados de vagas publicadas na plataforma, pesquisas com profissionais e informações de mercado de diversas fontes.

Os salários incluem benefícios?

Os valores apresentados são salários brutos mensais. Benefícios como VR, VA, plano de saúde e bônus são adicionais.

Com que frequência os dados são atualizados?

Os dados são atualizados trimestralmente para refletir as tendências mais recentes do mercado de trabalho brasileiro.
